# post-nasajobs

## Description

A mod tool specifically for r/nasajobs. This tool runs daily, fetches any newly posted NASA jobs from the usajobs.gov website. The application will run daily at 06:00 UTC but can be manually triggered by a mod from a menu option.

## User Data

This application does not collect, store, or process data about individuals.

## Settings

The mod may provide a flair ID which will be attached to the daily post. If nothing is provided, no flair will be attached to the post.

## Fetch Domains

The following domain is requested for this app:

- `data.usajobs.gov` - US government public job postings; source of the information to be posted
